# 会议同传提示台

面向会议管理员和同传人员的现场提示台。后台准备内容与现场可见内容明确分离，支持实时队列、术语提醒、紧急通知以及断网手工录入。

## 功能

- 主会场与两个分会场并行：各会场各自持有传译队列与上屏内容，互不干扰。
- 主控只维护议程（含场次会场归属）与术语表；调整场次归属时，该场次未确认条目跟到新会场，已上屏段落留在原会场。
- 译员转场：未确认条目跟随译员到新会场，已上屏段落留在原会场；转场整体一次提交，失败后归属保持原会场，可按原会场重试。
- 旧版本地数据没有会场归属：打开时先回填会场、场次与条目归属并写回，再启用应用。
- 自动接入现场文字并进入当前值守会场的传译队列；可手动模拟下一段。
- 逐条确认已传、补充遗漏、标记待跟进和清理重复提醒。
- 基于字符二元组相似度检测重复内容（按会场隔离）；延迟超过 8 秒显示警告。
- 术语表支持高优先级、指定译法、术语提醒和“已看到”确认。
- 紧急通知先保存后台，管理员明确发布后才进入现场可见区。
- 网络中断时继续手工录入本机暂存（归属录入时的会场）；恢复后合并并重新执行重复检查。
- 键盘优先：`J/K` 移动、`C` 确认、`N` 聚焦录入、`T` 术语提醒、`+/-` 调节字号。
- 浏览器本地持久化、撤销重做与字号偏好恢复。

## 技术栈

- SvelteKit、Svelte 5、TypeScript
- Tailwind CSS 3、Flowbite Svelte
- 浏览器 `localStorage`

## 本地开发

```bash
npm install
npm run dev
```

Vite 开发服务器监听 5173，仅属于开发环境；应用不定义宿主端口。

## 生产构建

```bash
npm install
npm run check
npm run build
```

静态产物位于 `build`，使用 `@sveltejs/adapter-static` 生成。

## Docker

```bash
docker build -t sologsb-1006 .
docker run --rm -p 10006:80 sologsb-1006
```

nginx 监听容器 80，并根据根端口表映射到宿主 `10006`。

## 数据说明

当前为纯前端离线演示，所有管理员配置、各会场队列和暂存内容保存在当前浏览器。每条队列条目都记录会场归属；旧版本地数据缺少归属字段时，打开应用会先按议程回填并写回，再投入使用。清理站点数据会移除本地记录。
